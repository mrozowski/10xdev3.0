## Notes

This is new concept. Implement Fruit Rush, it's Suika like game kept in retro stile fitting stylistikly to 10xgames platform. The player drops fruits into a container. Fruits fall under gravity and interact using simple physics. When two fruits of the same type touch, they merge into the next fruit in the progression.

The goal is to create the largest fruits possible and achieve the highest score before the container becomes too full. Fruit progression
